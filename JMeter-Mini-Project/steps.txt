5. Open JMeter
Step 1 – Create Test Plan

Open JMeter.

You will see:

Test Plan

Rename:

E-Commerce API Testing
6. Add Thread Group

Right Click:

Test Plan
→ Add
→ Threads (Users)
→ Thread Group
Configure:
Setting	Value
Number of Threads	10
Ramp-Up Period	5
Loop Count	5

Meaning:

10 users
Start in 5 seconds
Repeat 5 times
7. Add HTTP Request Defaults

Right Click Thread Group:

Add
→ Config Element
→ HTTP Request Defaults
Configure
Field	Value
Protocol	https
Server Name	fakestoreapi.com
8. Add HTTP Header Manager

Right Click Thread Group:

Add
→ Config Element
→ HTTP Header Manager
Add Headers
Name	Value
Content-Type	application/json
9. Add CSV Data Set Config

Right Click Thread Group:

Add
→ Config Element
→ CSV Data Set Config
Configure
Field	Value
Filename	users.csv
Variable Names	username,password
Delimiter	,
Recycle on EOF	True
Stop thread on EOF	False
10. Create Login API Request

Right Click Thread Group:

Add
→ Sampler
→ HTTP Request

Rename:

Login API
Configure
Field	Value
Method	POST
Path	/auth/login
Body Data
{
  "username": "${username}",
  "password": "${password}"
}
11. Add Response Assertion

Right Click Login API:

Add
→ Assertions
→ Response Assertion
Configure
Field	Value
Response Field	Text Response
Pattern Matching	Contains
Pattern	token

This checks whether login token exists.

21. Important Interview Questions
What is JMeter?

Apache JMeter is an open-source tool used for:

Load Testing
Performance Testing
API Testing
What is Thread Group?

Thread Group represents virtual users.

Difference Between Load Testing and Stress Testing
Load Testing	Stress Testing
Normal traffic	Extreme traffic
Checks performance	Checks breaking point
What is Throughput?

Number of requests processed per second/minute.

What is Ramp-Up Period?

Time taken to start all users.
